# Streamyfin Website

This is the official website for Streamyfin, the website provides information about the application, showcases its features and offers download links for supported platforms.

## Project Overview

The website is built with **Next.js**, **React**, **TypeScript** and **Tailwind CSS**, utilizing **shadcn/ui** components. It is designed to provide a somewhat consistent and accessible experience across desktop and mobile devices.

### Website Features

- Application presentation and feature overview.
- Interactive screenshot galleries.
- Platform-specific information and download links.
- Information about the Streamyfin companion plugin.
- Community links and project resources.

## Development

```bash
npm ci
npm run dev
```

The development server is available at [localhost:3000](http://localhost:3000).

Additional commands:

| Command | Description |
| :--- | :--- |
| `npm run build` | Production build |
| `npm run start` | Production server |
| `npm run lint` | ESLint |
